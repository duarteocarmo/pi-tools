# pi-session-breakdown

[![npm package](https://img.shields.io/npm/v/%40duarteocarmo%2Fpi-session-breakdown?label=npm)](https://www.npmjs.com/package/@duarteocarmo/pi-session-breakdown)
[![Pi package](https://img.shields.io/badge/Pi-package-222222)](https://pi.dev/packages/@duarteocarmo/pi-session-breakdown)

Pi Session Breakdown summarizes your Pi sessions, messages, tokens, and costs over time. Use `/session-breakdown` to open the interactive report.

The extension is based on Armin Ronacher's [`session-breakdown.ts`](https://github.com/mitsuhiko/agent-stuff/blob/main/extensions/session-breakdown.ts) from [`mitsuhiko/agent-stuff`](https://github.com/mitsuhiko/agent-stuff).

## Install

Install only Pi Session Breakdown from npm:

```sh
pi install npm:@duarteocarmo/pi-session-breakdown
```

Install every Pi package in this repository from Git:

```sh
pi install git:github.com/duarteocarmo/pi-tools
```
