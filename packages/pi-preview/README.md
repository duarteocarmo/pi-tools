# pi-preview

[![npm package](https://img.shields.io/npm/v/%40duarteocarmo%2Fpi-preview?label=npm)](https://www.npmjs.com/package/@duarteocarmo/pi-preview)
[![Pi package](https://img.shields.io/badge/Pi-package-222222)](https://pi.dev/packages/@duarteocarmo/pi-preview)

Pi Preview opens the latest assistant response as an HTML page in your browser. Use `/preview` when you want to read the response outside the terminal.

[<video src="https://github.com/duarteocarmo/pi-tools/raw/master/packages/pi-preview/demo.mp4" controls width="100%"></video>](https://github.com/user-attachments/assets/a5c62fa4-aca1-4c82-8118-fe87403f15a5)

## Install

Install only Pi Preview from npm:

```sh
pi install npm:@duarteocarmo/pi-preview
```

Install every Pi package in this repository from Git:

```sh
pi install git:github.com/duarteocarmo/pi-tools
```

Part of [pi-tools](https://github.com/duarteocarmo/pi-tools).
