# pi-jumper

[![npm package](https://img.shields.io/npm/v/%40duarteocarmo%2Fpi-jumper?label=npm)](https://www.npmjs.com/package/@duarteocarmo/pi-jumper)
[![Pi package](https://img.shields.io/badge/Pi-package-222222)](https://pi.dev/packages/@duarteocarmo/pi-jumper)

Pi Jumper shows every live Pi session on the machine and marks each one as waiting for input, running, idle, stale, or failed. Press `Alt+J` or use `/jumper` to inspect sessions. Press `Enter` to jump to the selected tmux session or `x` to stop its Pi process without closing tmux.

[<video src="https://github.com/duarteocarmo/pi-tools/raw/master/packages/pi-jumper/demo.mp4" controls width="100%"></video>](https://github.com/user-attachments/assets/1d020254-a17b-41c6-9084-1766ed10c12c)

## Install

Install only Pi Jumper from npm:

```sh
pi install npm:@duarteocarmo/pi-jumper
```

Install every Pi package in this repository from Git:

```sh
pi install git:github.com/duarteocarmo/pi-tools
```

Part of [pi-tools](https://github.com/duarteocarmo/pi-tools).
