# pi-extensions-doc

| Package | What it does |
| --- | --- |
| `@duarteocarmo/pi-jumper` | Lists live Pi sessions and jumps between tmux panes. |
| `@duarteocarmo/pi-no-sleep` | Prevents macOS display sleep while enabled. |
| `@duarteocarmo/pi-preview` | Opens the latest assistant response as HTML in a browser. |
| `@duarteocarmo/pi-session-breakdown` | Shows session, message, token, and cost statistics. |
| `@duarteocarmo/pi-subagents` | Runs bounded isolated Pi subagents. |
| `@duarteocarmo/pi-modus-themes` | Provides Modus themes and follows macOS light or dark appearance. |
| `pi-helicopter` | Shows local Pi usage in the macOS menu bar. |
