# Duarte's pi tools

Extensions, themes and apps I use with [pi](https://pi.dev/)

| Name | What it does | Install with |
| --- | --- | --- |
| [`pi-jumper`](./packages/pi-jumper) | /jumper: jump and monitor other pi sessions running on tmux | `pi install npm:@duarteocarmo/pi-jumper` |
| [`pi-no-sleep`](./packages/pi-no-sleep) | /no-sleep: prevent macOS sleep while running pi | `pi install npm:@duarteocarmo/pi-no-sleep` |
| [`pi-preview`](./packages/pi-preview) | /preview: open assistant message in a nice browser window | `pi install npm:@duarteocarmo/pi-preview` |
| [`pi-subagents`](./packages/pi-subagents) | My shitty subagent extension | `pi install npm:@duarteocarmo/pi-subagents` |
| [`pi-modus-themes`](./packages/pi-modus-themes) | Modus themes for Pi - they were missing | `pi install npm:@duarteocarmo/pi-modus-themes` |
| [`pi-helicopter`](./packages/pi-helicopter) | A lightweight menu bar app to monitor your pi usage | `brew install --cask duarteocarmo/pi-tools/pi-helicopter` |
